#  默认共享 /opt/files（就是 eMMC 剩余空间那块盘，见 Scripts/Settings.sh 的 docker-storage），

#  注意：官方模板里写死了 invalid users = root，所以 root 不能登录 SMB；
#  要用账号密码就自己 adduser + smbpasswd -a，再把共享里的"允许访客"关掉。
